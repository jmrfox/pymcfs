# toric_spines

Personal research workspace for toric-spine / TS mesh skeletonization workflows.
This tree lives on **`main` only** — it is not on the public `release` branch.

## Layout

- `notebooks/` — Jupytext percent scripts + paired notebooks
- `scripts/` — batch / search / sweep / demo drivers for TS meshes
- `data/mesh/` — input meshes (`TS*.obj` and primitives)

Outputs default under repo-root `outputs/` (gitignored) or paths set by each script.
