# Settings

Frozen dataclasses for contraction and the post-conversion refine phase.
Pass a `SkeletonizeSettings` (or nested pieces) to `skeletonize` /
`contract_mesh` / `search_mcfs_params`, or override individual fields with
keyword arguments.
